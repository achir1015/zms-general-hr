iPhone（直向）／iPad（橫向）

安裝到這台 iPhone／iPad 查看更新內容

安裝步驟

  1. 請用 Safari 開啟本頁，按上方「安裝」，在對話框按「安裝」。
  2. 回到主畫面等待圖示下載完成。
  3. 第一次開啟：請人資在電腦版「系統管理 → 手機打卡與連線」打開服務，用相機掃描畫面上的 QR Code 即可連線，再用自己的帳號登入。
  4. 第一次連線時請允許「尋找區域網路上的裝置」；若出現「No route to host」，請到「設定 → App → 資料助秘之一般公司人事薪資差勤」（或「設定 → 隱私權與安全性 → 區域網路」）打開「區域網路」，再按「連線」。
  5. 員工帳號會直接進入「我的打卡與假勤」：第一次打卡時請允許「使用位置資訊」，系統用 GPS 確認您在公司打卡範圍內。
本版為內部測試發佈（Ad Hoc），只有已登記的裝置可以安裝。若出現「無法安裝」，代表這台裝置尚未登記，請洽系統管理員。
